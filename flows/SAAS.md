# Flow: SaaS / Software

Read this after intent is identified as SaaS. It overrides and extends `interview/SKILL.md`'s generic questions — ask these on top, not instead.

## Ask these, on top of the generic 5

1. **Price point?** Free/freemium / <$50mo / $50-500mo / $500+mo / enterprise.
   Why: sets page length, proof density, and CTA friction — a $500+/mo product needs a long page with heavy proof; a <$50/mo product needs a short page and a fast CTA.
2. **Free trial or demo-first?**
   Trial → hero CTA is "Start free," low friction. Demo → hero CTA is "See it in [time]," backed by calendar or video.
3. **Tool they use daily or occasionally?**
   Daily → emphasize workflow integration, speed, UX. Occasionally → emphasize reliability, being there when needed.
4. **Do you have screenshots or a demo?**
   Yes → use real product shots throughout. No → do NOT fabricate a UI mockup — see Edge Cases below.

## Section Template

1. Hero: problem-aware headline + primary CTA + product screenshot
2. Social proof bar: 4-6 customer logos
3. Problem agitation: what's broken about the current way
4. Product reveal: screenshot or demo video in context of use
5. Features as benefits: 3-4 max, user-language, each paired with a visual
6. How it works: 3 steps max
7. Testimonials: specific results, real names, real photos
8. Pricing: transparent tiers, if applicable
9. FAQ: security, integrations, cancellation — the real objections
10. Final CTA + risk reducer: "14-day free trial, no credit card"

## Copy Direction

- Cold traffic → lead with the problem: "Your team spends 11 hours a week in spreadsheets."
- Warm traffic → lead with the solution: "One dashboard for your entire pipeline."
- Price <$50/mo → shorter page, less proof needed, fast CTA.
- Price $500+/mo → long page, heavy social proof, demo before buy.
- Enterprise → add a "Talk to sales" secondary CTA alongside self-serve.

## Edge Cases

- No screenshots yet → use before/after workflow descriptions instead of UI shots. Never fabricate a mockup (CLAUDE.md escape hatch).
- Freemium with premium upsell → hero CTA is free; the pricing section shows the upgrade path.
- Developer tool → code snippets can replace screenshots; a docs link works as the secondary CTA.
