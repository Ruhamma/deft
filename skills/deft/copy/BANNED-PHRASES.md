# Banned Phrases — The Full Slop Vocabulary

Reference tables for `copy/COPY.md`'s hard bans (C-01 through C-13). These words and phrases are the mathematical average of all marketing copy ever written — technically fine, immediately generic. Scan every visible string against these lists before presenting copy for approval.

---

## Banned Verbs

| Banned Verb | Why It's Slop | Reach for Instead |
|---|---|---|
| Revolutionize | Every product "revolutionizes." None do. | Name the specific change: "cuts onboarding from 3 weeks to 3 hours" |
| Transform | Vague shape-shifting. The #1 AI headline formula. | Name the before and after: "Stop guessing which leads are real" |
| Elevate | Means "make better," communicates nothing | Describe the actual improvement |
| Empower | Patronizing — implies the user is powerless without you | Show capability: "Build dashboards without writing SQL" |
| Streamline | The single most overused AI marketing verb | Name what gets faster: "One click replaces your 14-step approval chain" |
| Unleash | Melodramatic for software | Name the constraint you remove |
| Supercharge | Car-commercial energy | Be concrete: "3x faster than doing it manually" |
| Leverage | Corporate jargon, zero meaning | "Use" — or describe the specific action |
| Optimize | Can mean literally anything | Name the metric: "Cut page load time to under 2 seconds" |
| Accelerate | Vague speed promise | Specify: "Ship campaigns in hours, not weeks" |
| Harness | Nobody harnesses anything outside of horses | Describe the specific action and outcome |
| Unlock | Unless you sell locks | Name what becomes possible |
| Amplify | Vague intensity increase | "Reach 10x more prospects with the same budget" |
| Drive | "Drive results" — drive what where? | Name the result and the mechanism |
| Catalyze | Academic jargon pretending to be marketing | Describe the actual cause and effect |
| Redefine | Unless you're literally changing a definition | Say what's different |
| Reimagine | The "we have no idea what's actually new" verb | Describe the new thing directly |
| Synergize | Should have died in 2005 | Describe the actual integration |
| Delve | The clearest AI tell there is | "Here's how it works" |
| Discover | "Discover the difference" — discover what? | Name the thing they'll find |

## Banned Adjectives & Adverbs

| Banned Word | Why It's Slop | Replacement Principle |
|---|---|---|
| Seamless | The most meaningless word in tech marketing | "No CSV exports. No copy-pasting between tabs." |
| Cutting-edge | Says "advanced" without saying how | Name the technology or approach |
| Next-generation | Same as cutting-edge but worse | Describe what's actually new |
| State-of-the-art | Academic language, not marketing | Show, don't label |
| Robust | Means "it works" — the bare minimum | "Handles 10M+ rows without lag" |
| Scalable | Every SaaS claims this | "Grows with you — 5 users to 5,000, same plan" |
| Holistic | Wellness-brand energy, vague | Name the specific components |
| Comprehensive | Tells nothing about what's included | List the things |
| Intuitive | Every UI claims this; users disagree | "No training needed" |
| Effortless | Nothing is effortless — it's a lie | "Takes 3 clicks" |
| Innovative | Self-praise; the user decides this | "The first platform that [specific thing]" |
| Powerful | Powerful how? For what? | "Process 100K transactions per second" |
| Dynamic | Means "it changes" — that's all software | Describe what changes and why it matters |
| Game-changing | Hyperbolic | Name what it replaces |
| World-class | Unverifiable self-praise | "Used by [specific impressive customers]" |
| Unparalleled | Same problem as world-class | "Rated #1 on G2 for [category]" |
| Frictionless | Sibling of seamless, equally empty | Describe what friction was removed |
| End-to-end | Can mean anything | Name the actual start and end points |
| Blazing-fast | Every app claims this | "Loads in 0.3 seconds" |
| Groundbreaking | Unless you sell excavation equipment | Describe what ground was broken |
| Actionable | "Actionable insights" — what does that mean? | "Shows you exactly what to fix and how" |
| Bespoke | Only appropriate for Savile Row tailors | "Custom" or "built for your workflow" |
| Thoughtfully designed | Self-congratulatory | Don't say it — show it |

**The Adjective Test (Harry Dry):** try the sentence with the adjective removed. If it still works, the adjective was dead weight — cut it. If it doesn't, the adjective was hiding a fact; replace it with that fact.

## Banned Phrases

- **The "Your X" formula:** "Your all-in-one solution for…", "Your one-stop shop for…", "Your trusted partner in…", "Your gateway/path/key to…"
- **The "Built for" formula:** "Built for modern teams", "Built for the future", "Designed with you in mind", "Purpose-built for…"
- **The "Experience the" formula:** "Experience the power of…", "Experience the difference"
- **The "Say goodbye" formula:** "Say goodbye to [pain]", "Say hello to [product]"
- **The "Join X" formula:** "Join thousands of…", "Join the revolution", "Trusted by thousands"
- **The "It's time" formula:** "It's time to rethink…", "The future of X is here"
- **The "No X. No Y. Just Z." formula:** "No complexity. No hassle. Just results." — the single most-cited AI tell on Reddit. Hard ban, no exceptions.
- **The "Whether you're" formula:** "Whether you're a startup or enterprise…", "For teams of all sizes"
- **General slop:** "At the intersection of X and Y", "Take your X to the next level", "In today's fast-paced world…", "We believe that…", "More than just a [category]", "So you can focus on what matters most", "Everything you need, nothing you don't", "Simple, yet powerful", "The last X you'll ever need", "X, reimagined", "Do more with less"
- **Academic transitions:** "Moreover", "Furthermore", "Additionally", "It's worth noting" — marketing copy uses short paragraphs and visual breaks, never transition words.

## The Em-Dash Rule

**Zero em dashes. Not one, not a budget: none.** The #1 cited AI copy tell. Rewrite around every one with a period, a colon, a comma, or a restructured sentence. If a sentence needs an em dash to work, it's too complex for landing page copy. This covers all visible copy including the title tag, meta description, and alt text, and it also catches `--` and `&mdash;`.

## Banned Structural Patterns

- **The parallel triple** ("Plan. Track. Deliver."): max one per page, and all three items must be non-interchangeable and specific.
- **The feature-benefit pair** ("Smart Analytics — get actionable insights that drive growth"): replace with the user's problem stated directly.
- **The rhetorical question opener** ("Tired of managing spreadsheets?"): never in the hero, max one elsewhere on the page.
- **The vague social proof claim** ("Trusted by thousands of companies worldwide"): always needs a real number and a real name.
- **The "We" opener** ("We provide…", "We built…", "Our platform enables…"): hero and the first three section headings must use "you" or the user's outcome as the subject.
- **The padding paragraph:** in any 3+ sentence paragraph, sentences 2 and 3 must add new information or get cut.
- **The hedging qualifier** ("can help you potentially improve…", "is designed to help…"): rewrite as a direct claim. Don't say "we help" — say "it's how." Don't say "alternative" — say "replaces."
- **The comma-list feature dump** ("offers project management, team collaboration, time tracking, invoicing, reporting, and more"): pick the one or two things that matter most.
- **The vague stats bar** ("Upto 30% in costs", no source): every number needs context and, where real, a source.

## Banned Headline Formulas

| Formula | Example | Why It Fails |
|---|---|---|
| [Verb] Your [Noun] | "Transform Your Workflow" | Vague verb + vague noun = zero meaning |
| The [Adjective] Way to [Verb] | "The Smarter Way to Manage Projects" | Claims superiority without evidence |
| Where X Meets Y | "Where Productivity Meets Simplicity" | The most AI-slop headline structure there is |
| [Category], Reimagined | "Project Management, Reimagined" | Can't articulate what's new |
| The Future of [Category] | "The Future of Team Communication" | Says nothing about the present |
| Not Just X | "Not Just Chat" | Defines itself by what it's not |
| Stop [Pain]. Start [Benefit]. | "Stop Guessing. Start Growing." | Was clever once; now dead |
| Do More [Preposition] [Noun] | "Do More With Less" | Generic aspiration, no content |

## Banned CTAs

| Banned CTA | Why It Fails |
|---|---|
| Get Started | Started with what? The most generic CTA that exists. |
| Learn More | Passive — delays the decision |
| Request a Demo | Feels like a sales trap |
| Sign Up Free | Transactional and cold |
| Try It Now | What is "it"? |
| Unlock Your Potential | Meaningless |
| Schedule a Call | Sounds like work |
| Discover More | Passive discovery language |
| Join Now | Join what? |

CTA replacement principles: name the outcome, not the action ("Get Started" → "Build your first dashboard"); reduce perceived effort ("Request a Demo" → "See it in 2 minutes, no login needed"); match CTA intensity to the section's job (hero = primary action, mid-page = evidence-based, final = urgency/finality); one primary + one secondary max per section.

## Microcopy Slop

| Slop | Replacement |
|---|---|
| "Solutions" / "Resources" / "Platform" in nav | Name the thing: "Pricing", "Templates", "API Docs" |
| "Home" in the nav | The logo click is home — everyone knows this |
| 7+ nav items | Max 5 |
| "Submit" button | Name the action: "Create Account", "Send Message" |
| "Please enter your…" | Drop it — it's a form, they know |
| "This field is required" | "We need your email to send the report" |
| "Trusted by leading companies" | Name 3-5 actual companies |
| "Join 10,000+ users" | "12,847 teams and counting" — odd numbers feel real |
| Generic 5-star rating | "4.8/5 from 2,340 reviews on G2" — source matters |
| Stock photo testimonials | Real photos or no photos. Fake photos destroy trust. |
