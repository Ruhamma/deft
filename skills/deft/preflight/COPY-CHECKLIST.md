# Copy Preflight Checklist

Referenced by `preflight/PREFLIGHT.md`. Hard checks are auto-fixed, no user input needed. Soft checks get flagged for the user to weigh in on.

## Hard Checks — Fix Automatically

**C-01: Banned verb scan.** Scan all visible copy for verbs from `copy/BANNED-PHRASES.md`'s banned verb list. Found → replace with the specific alternative it lists.

**C-02: Banned adjective scan.** Scan for adjectives from the banned adjective list. Found → replace with a specific qualifier, or remove.

**C-03: Banned phrase scan.** Scan for complete phrases from the banned phrase list. Found → rewrite entirely.

**C-04: Em-dash scan.** Scan all visible copy, including the title tag, meta description, and image alt text, for em dashes (—) plus `--` and `&mdash;`. The count must be 0. Any occurrence → rewrite around it with a period, colon, or comma. Zero is the standard, not a budget of one.

**C-05: "We" subject check.** Check whether "We"/"Our" is the grammatical subject in the hero headline, hero subhead, or the first three section headings. Found → rewrite to "You" or the user's outcome as the subject.

**C-06: Banned CTA scan.** Check every CTA button against the banned CTA list. Found → replace with an outcome-focused CTA per `copy/COPY.md`'s replacement principles.

**C-07: Hedging qualifier scan.** Scan for "can help," "may enable," "is designed to help," "aims to provide," "potentially improve." Found → rewrite as a direct claim.

**C-08: Padding paragraph check.** For each paragraph with 3+ sentences, check whether sentences 2 and 3 add new information beyond sentence 1. If not → condense to one sentence.

**C-09: Parallel triple count.** Count instances of the three-item parallel structure ("Plan. Track. Deliver."). More than 1 on the page → remove or rewrite the extras.

**C-10: Transition word scan.** Scan for "Moreover," "Furthermore," "Additionally," "It's worth noting," "It should be noted." Found → remove or rewrite.

**C-11: Buzzword density.** Scan for "streamline," "empower," "supercharge," "world-class," "enterprise-grade," "next-generation." Found → replace with the specific verb + noun describing what the product literally does.

**C-12: Aphoristic cadence check.** Scan for "Not a [noun]. A [noun]." / "Not just [X]. [Y]." More than 1 instance → rewrite the extras.

**C-13: Theater framing check.** Scan for "[noun] theater," "performance theater," "growth theater." Found → rewrite plainly.

## Soft Checks — Flag for User Review

**C-14: Specificity audit.** Does the hero headline pass the Only You Test — could a competitor use it unchanged? If yes → flag and suggest a more specific alternative.

**C-15: Six-word test.** Can the hero value proposition be communicated in 6 words? If not → flag for potential simplification.

**C-16: Social proof specificity.** Are social proof claims specific (real number, real company, real source)? If vague → flag and suggest a specific alternative.

**C-17: Conviction check.** Does the copy use "we help" / "we offer" / "an alternative to" language? If yes → flag and suggest direct conviction language per the Conviction Rule.
